# Как устроена карта

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Оболочка страницы: шапка, карта, карточка, подвал. Подключает Leaflet 1.9.4 с cdnjs и шрифты. |
| `assets/style.css` | Стили, включая цвета слоёв карты. Цвета — токены в `:root`, есть тёмная тема. |
| `assets/app.js` | Вся логика сайта: слои, масштабы, карточка, поиск, личные пометки, ссылки. |
| `data/map.json` | Тексты и метки районов и областей. Пишется руками. |
| `data/areas.tsv` | Крупные области: id и название. |
| `data/cities.tsv` | Города по переписи 2000 года: русское название и область. |
| `data/seeds.tsv` | Районы: опорные точки, по которым режется территория. |
| `data/geo/*.geojson` | Готовая геометрия. Собирается скриптом, руками не правится. |
| `data/geo/legacy.json` | Какие клетки старой карты лежат под районом. Собирается скриптом. |
| `data/legacy/grid-2005.json` | Данные старой карты в клетку, как они были в октябре 2026 года. |
| `data/raw/` | Скачанные сырые данные, в репозиторий не попадают. |
| `tools/` | Скрипты сборки (Python 3.11, нужны `shapely` и `pyshp`). |

## Сборка геометрии

```
pip install shapely pyshp
python tools/fetch.py     # скачать OSM и перепись в data/raw/ (один раз)
python tools/build.py     # собрать data/geo/*.geojson
python tools/legacy.py    # сопоставить районы со старой картой
python tools/geocheck.py  # необязательно: сверить точки районов с геокодером OSM
```

Скрипты запускаются из корня репозитория. `build.py` работает около 30 секунд.

### Как режутся районы

1. Территория режется на куски линиями: фривеи и главные улицы (`motorway`, `trunk`, `primary` в OSM), основное русло Тринити, магистральные железные дороги, крупные озёра, аэродромы-районы и городская черта 2000 года.
2. Каждый кусок относится к тому городу, которому принадлежит больше половины его площади.
3. Кусок достаётся опорной точке района из `seeds.tsv` того же города: той, что внутри куска, или ближайшей. Если в одном куске оказались точки двух районов, кусок дорезается улицами второго уровня (`secondary`), а если и это не помогло — посередине между точками.
4. Город без своих точек в `seeds.tsv` становится одним районом с id `c-<имя>` (например, `c-highland-park`).
5. Земля вне городов достаётся ближайшему сельскому району (город `-` в `seeds.tsv`) не дальше 15 км, остальное прирастает к соседям.
6. Мелкие куски на развязках прилипают к соседу с самой длинной общей границей, оторванные кусочки района — тоже.
7. Область = объединение её районов. Соседние области получают разные цвета (6 тонов), районы берут цвет своей области.

### Как поправить границу

Добавь району в `seeds.tsv` ещё одну строку с тем же id и точкой там, куда район должен дотянуться. Или подвинь точку. Потом пересобери. Если точка попала в чужой город или в кусок другого района, `build.py` об этом напишет.

### Анахронизмы

`tools/build.py`, в начале: `ANACHRONISM_ROADS` (по названию и номеру: Margaret Hunt Hill Bridge, Chisholm Trail Parkway, все экспресс-полосы TEXpress, платная SH 360), `ANACHRONISM_PARKS` (Klyde Warren Park и новые скверы даунтауна) и функция `anachronism_way` (западное продолжение платной дороги Буша по SH 161 южнее SH 183 и восточное продолжение до Роулетта). Из линий DART оставлены только Красная и Синяя, Синяя обрезана до Ledbetter и Downtown Garland. Если найдёшь ещё что-то позднее 2005 года, добавляй туда же.

## Формат data/map.json

```json
{
 "schema": 2,
 "updated": "2026-10-26",
 "areas": {
  "dal-center": {"marker": "", "label": "", "summary": "", "details": "", "more": "", "notes": ""}
 },
 "districts": {
  "prestonhollow": {"marker": "important", "label": "Элизиум", "summary": "", "details": "", "more": "", "notes": ""}
 }
}
```

Названия районов и областей берутся из `seeds.tsv`, `areas.tsv` и `cities.tsv`, а не из этого файла.

| Поле | Значение |
|---|---|
| `marker` | `""`, `"haven"` (убежище), `"ally"` (союзники), `"hostile"` (враждебность), `"important"` (важное место). |
| `label` | Подпись метки, например «Элизиум». |
| `summary` | Одна строка под заголовком. |
| `details` | Основное описание. Абзацы через пустую строку (`\n\n`). Пока его нет, в карточке показываются тексты старой карты. |
| `more` | Необязательный развёрнутый рассказ, раскрывается кнопкой «Подробнее». |
| `notes` | Заметки мастера, видны всем отдельным блоком. |

## Масштабы

С масштаба `DETAIL_ZOOM` (12) кликаются районы, мельче — области. Подписи районов появляются по мере приближения: на каждом шаге масштаба показываются районы вчетверо меньше. Кнопки «Области» и «Районы» в шапке переключают масштаб.

## Личные пометки

`localStorage`, ключ `vtm-dallas-2005-map.personal.v1`:

```json
{"items": {"d:prestonhollow": {"marker": "hostile", "label": "Засада", "notes": "…"}, "a:dal-center": {…}}, "updated": "…"}
```

`d:` — район, `a:` — область. Импорт понимает и этот формат, и файл пометок старой карты (`{"cells": {"city:D5": …}}`).

## Ссылки

`#d/<id района>`, `#a/<id области>`. Старые ссылки `#city-D5`, `#core-B4`, `#fw-E6` открывают район, в котором лежит центр клетки.

## Правила для описаний

1. Всё по состоянию на весну 2005 года. Если факт не проверить, лучше не писать.
2. Описывай то, что физически лежит в границах района. Границы видны на карте и в `data/geo/districts.geojson`.
3. Район: 60–160 слов в `details` — из чего состоит, кто живёт, что ночью, опасность, полиция, чем полезен вампиру. Подробности — в `more`, 300–500 слов, только если есть что рассказать.
4. Область: общий характер в 2–4 абзаца, без перечисления всех районов.
5. Язык простой и живой, как у знающего друга, который объясняет мастеру из постсоветского пространства, ни разу не бывавшему в Техасе. Без канцелярита, маркированных списков, эмодзи и рекламного тона.
6. Названия мест транслитерируются по-русски («Дип-Эллум»), названия учреждений можно оставлять по-английски («Parkland»).
7. Никаких личных секретов игроков и закулисья мастера.
8. Реальные люди — только исторический фон, без сюжетных ролей.
