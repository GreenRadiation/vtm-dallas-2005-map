# Как устроена карта

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Оболочка страницы: шапка с кнопками, карта, карточка, подвал. Leaflet 1.9.4 с cdnjs и шрифты. |
| `assets/style.css` | Стили, включая цвета слоёв карты. Цвета — токены в `:root`, есть тёмная тема. |
| `assets/app.js` | Логика сайта: масштабы и режимы, карточки, поиск, личные пометки, ссылки. |
| `data/map.json` | Тексты и метки регионов. Пишется руками. |
| `data/areas.tsv` | Крупные области: id и название. |
| `data/cities.tsv` | Города по переписи 2000 года: русское название и область. |
| `data/seeds.tsv` | Районы среднего масштаба: опорные точки. |
| `data/natural.tsv` | Озёра и большие парки, которые становятся отдельными регионами. |
| `data/seeds3.tsv` | Ручная нарезка мелкого масштаба (сейчас — центр Далласа). |
| `data/geo/*.geojson` | Готовая геометрия: `l1` (области), `l2` (районы), `l3` (секторы), `labels`, `roads`, `water`, `rail`, `green`. Собирается скриптом, руками не правится. |
| `data/geo/regions.txt` | Список районов с площадью и числом секторов — для проверки глазами. |
| `data/legacy/grid-2005.json` | Тексты старой карты в клетку. На сайте не показываются, это справочный материал для новых описаний. |
| `data/raw/` | Скачанные сырые данные, в репозиторий не попадают. |
| `tools/` | Скрипты сборки (Python 3.11, нужны `shapely` ≥ 2.1, `pyshp`, `numpy`). |

## Сборка геометрии

```
pip install shapely pyshp numpy
python tools/fetch.py     # скачать OSM и перепись в data/raw/ (один раз)
python tools/build.py     # собрать data/geo/*
python tools/geocheck.py  # необязательно: сверить точки районов с геокодером OSM
```

Скрипты запускаются из корня репозитория. `build.py` работает меньше минуты и печатает предупреждения: точка района попала в чужой город или в чужой кусок, району не досталось территории, осталась дыра.

### Три масштаба

**Средний (районы, `l2`).**
1. Территория режется на куски: фривеи и главные улицы, магистральные железные дороги, русло Тринити, аэродромы-районы, природные регионы и городская черта 2000 года. Черта предварительно сглажена как единое покрытие (`coverage_simplify`, 400 м): зубцы и узкие выступы пропадают, щелей между городами нет.
2. Город куска — тот, кому принадлежит большая часть его площади. Кусок достаётся опорной точке района из `seeds.tsv` того же города: той, что внутри куска, или ближайшей. Город без своих точек становится одним районом (`c-<имя>`). Земля вне городов — ближайшему сельскому району (город `-`).
3. Мелочь на развязках и узкие полоски между параллельными дорогами (их сначала режут на куски по 600 м) прилипают к соседу с самой длинной общей границей.
4. Слишком большие районы делятся на части примерно равной площади (k-средних по точкам внутри района, граница по дорогам, где они есть, иначе прямая посередине). Порог зависит от типа области: центр 10 км², город 16, пригород 28, сельская местность 70 (`L2_MAX`). Части называются по сторонам света: «Карролтон, юго-запад», id — `<район>-sw`.
5. Границы всех районов сглаживаются согласованно (`coverage_simplify`, 300 м).

**Мелкий (секторы, `l3`).** Каждый район делится на секторы примерно равной площади: в центре 1,4 км², в городе 3, в пригороде 5, в сельской местности 15 (`L3_TARGET`). Если у района есть строки в `seeds3.tsv`, он режется по ним, а названия берутся оттуда. Иначе — «<район>, север», «центр», «ближний юг» и т. п., id — `<район>.<направление>`. Озёра, парки и аэропорты не делятся.

**Крупный (области, `l1`).** Объединение районов по полю «область».

Соседние области раскрашены разными цветами (6 тонов), соседние районы и секторы внутри — разными оттенками (3 оттенка).

### Как поправить границу

Добавь району в `seeds.tsv` ещё одну строку с тем же id и точкой там, куда район должен дотянуться, или подвинь точку. Для мелкого масштаба — строки в `seeds3.tsv`. Потом пересобери. Если меняется геометрия, id частей и секторов (`-sw`, `.n`) могут сдвинуться; тексты в `map.json` для них придётся перенести.

### Анахронизмы

В начале `tools/build.py`: `ANACHRONISM_ROADS` (Margaret Hunt Hill Bridge, Chisholm Trail Parkway, все экспресс-полосы TEXpress, платные продолжения SH 360), `ANACHRONISM_PARKS` (Klyde Warren Park и новые скверы даунтауна), `anachronism_way` (западное продолжение платной дороги Буша по SH 161 и восточное до Роулетта), `LATER_NAMES` (поздние названия дорог). Из линий DART оставлены Красная и Синяя, Синяя обрезана до Ledbetter и Downtown Garland. Lake Viridian (2010-е) не включён в природные регионы.

## Сайт

### Режимы и масштабы

Кнопки в шапке:

- **Районы / Дороги.** В режиме районов кликаются регионы, дороги бледные и не кликаются. В режиме дорог регионы — бледный фон крупных областей, а фривеи и большие улицы яркие, с названием при наведении и карточкой по клику.
- **Авто / Крупный / Средний / Мелкий.** Показан только один масштаб регионов, без смешения. В «Авто» он выбирается по приближению: до zoom 11 крупный, до 12.5 средний, дальше мелкий (`AUTO` в `app.js`); подчёркнутая кнопка показывает, какой масштаб сейчас выбран автоматически. Поверх тонких границ текущего масштаба рисуются толстые границы старших.

Подписи ставятся без наложения: сначала важные, остальные — если есть место.

### Формат data/map.json

```json
{
 "schema": 3,
 "updated": "2026-10-27",
 "areas": {"dal-east": {"marker": "", "label": "", "summary": "", "details": "…", "more": "", "notes": ""}},
 "districts": {"prestonhollow": {"marker": "important", "label": "Элизиум", "details": "…", …}},
 "sectors": {"anatole": {"marker": "important", "label": "Отель Барона", …}}
}
```

Ключи — id из `l1`, `l2`, `l3`. Названия берутся из геометрии, а не из этого файла.

| Поле | Значение |
|---|---|
| `marker` | `""`, `"haven"`, `"ally"`, `"hostile"`, `"important"`. Метка района видна пунктиром и на его секторах. |
| `label` | Подпись метки. |
| `summary` | Необязательная строка под заголовком. |
| `details` | Описание. Сейчас у областей и районов — 1–2 предложения. Если у сектора своего текста нет, в карточке показывается описание его района. |
| `more` | Необязательный развёрнутый рассказ под кнопкой «Подробнее». |
| `notes` | Заметки мастера, видны всем. |

### Дороги

`data/geo/roads.geojson`: фривеи сгруппированы по номеру, улицы — по названию и разбиты на связные куски. Поля: `cls`, `id`, `ref`, `name`, `aka`, `lanes` (полос в одну сторону), `speed` (миль/ч), `toll`, `km`, `areas` (id областей по пути). Полосы и скорость — из современного OSM, в карточке это оговорено.

### Личные пометки

`localStorage`, ключ `vtm-dallas-2005-map.personal.v1`: `{"items": {"d:prestonhollow": {"marker": "…", "label": "…", "notes": "…"}}}`. `a:` — область, `d:` — район, `s:` — сектор. Импорт понимает и файл пометок старой карты в клетку (клетка ложится на район в её центре). Выбранные режим и масштаб помнятся под `vtm-dallas-2005-map.view`.

### Ссылки

`#a/<id>`, `#d/<id>`, `#s/<id>`, `#r/<id дороги>`. Старые ссылки `#city-D5`, `#core-B4`, `#fw-E6` открывают район в центре клетки.

## Правила для описаний

1. Всё по состоянию на весну 2005 года. Если факт не проверить, лучше не писать.
2. Описывай то, что лежит в границах региона.
3. Сейчас у областей и районов короткие описания (1–2 предложения, характер места). Подробности (`more`) — потом, когда будем копать конкретные места; материал — тексты старой карты в `data/legacy/grid-2005.json`.
4. Язык простой и живой, как у знающего друга, который объясняет мастеру из постсоветского пространства. Без канцелярита, списков, эмодзи и рекламы.
5. Названия мест транслитерируются по-русски, названия учреждений можно оставлять по-английски.
6. Никаких личных секретов игроков и закулисья мастера. Реальные люди — только исторический фон.
