# Как устроена карта

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Оболочка страницы: шапка с кнопками, карта, карточка, подвал. Leaflet 1.9.4 с cdnjs и шрифты. |
| `assets/style.css` | Стили, включая цвета слоёв карты. Цвета — токены в `:root`, есть тёмная тема. |
| `assets/app.js` | Логика сайта: раскрытие веток дерева, карточки, поиск, личные пометки, ссылки. |
| `data/map.json` | Тексты, метки и ручные теги регионов, озёр и парков. Пишется руками. |
| `data/census.json` | Перепись 2000 года по узлам дерева (кто живёт, доход, жильё). Собирает `tools/census.py`, руками не правится. |
| `data/tree.tsv` | Дерево регионов: id, родитель, вид (город, аэродром, знаковое место, группа), название, опорные точки. Пишется руками, см. [TREE.md](TREE.md). |
| `data/natural.tsv` | Озёра и большие парки — слой поверх дерева. |
| `review.html` | Список всех регионов со ссылками на Google Maps — для сверки. |
| `data/geo/tree/` | Готовая геометрия дерева: `_root.geojson` (верхний уровень), `<id>.geojson` (дети узла), `index.json` (все узлы: родитель, название, точка подписи, рамка), `aliases.json` (куда ведут ссылки и пометки прежних карт). Собирается скриптом, руками не правится. |
| `data/geo/*.geojson` | `nature` (озёра и парки), `water`, `green`. Тоже собираются скриптом. |
| `data/geo/regions.txt` | Дерево с площадями — для проверки глазами. |
| `data/legacy/` | Прежние версии: тексты карты в клетку (`grid-2005.json`), тексты и список регионов карты в четыре масштаба (`map-v4.json`, `review-v4.json`). На сайте не показываются; `review-v4.json` нужен сборке для таблицы старых ссылок. |
| `data/raw/` | Скачанные сырые данные, в репозиторий не попадают. |
| `tools/` | Скрипты сборки (Python 3.11, нужны `shapely` ≥ 2.1, `pyshp`, `numpy`, `scipy`). |

## Сборка геометрии

```
pip install shapely pyshp numpy scipy
python tools/fetch.py     # скачать OSM и перепись в data/raw/ (один раз)
python tools/build.py     # собрать data/geo/*
python tools/census.py    # перепись 2000 по узлам → data/census.json (после build.py; качает ~70 МБ один раз)
python tools/geocheck.py  # необязательно: сверить опорные точки дерева с геокодером OSM
```

Скрипты запускаются из корня репозитория. `build.py` работает около 20 секунд. Если проверки (см. REGIONS.md) не прошли, он печатает ошибки и не перезаписывает карту; `--force` записывает всё равно, для отладки.

### Регионы

Как устроено дерево и как его править — [TREE.md](TREE.md); как режется геометрия и какие проверки выполняет сборка — [REGIONS.md](REGIONS.md). Если проверки не прошли, сборка не перезаписывает карту. Список всех регионов для сверки — страница `review.html` (данные — `data/geo/review.json`).

### Анахронизмы

В начале `tools/build.py`: `ANACHRONISM_ROADS` (Margaret Hunt Hill Bridge, Chisholm Trail Parkway, все экспресс-полосы TEXpress, платные продолжения SH 360), `ANACHRONISM_PARKS` (Klyde Warren Park и новые скверы даунтауна), `anachronism_way` (западное продолжение платной дороги Буша по SH 161 и восточное до Роулетта). Дороги и железные дороги на карту не выводятся, но служат барьерами при нарезке регионов, поэтому анахронизмы из них тоже вырезаются. Lake Viridian (2010-е) не включён в природные регионы.

## Сайт

### Дерево

- Сначала видны только верхние узлы (города и пригороды). Клик — карточка. Двойной клик или «Раскрыть» в карточке раскрывает узел: на его месте появляются дети, сам он остаётся толстым контуром. Раскрыта всегда одна ветка; раскрытие другого узла сворачивает прежнюю ветку до общего предка. Простой клик ничего не сворачивает. «Свернуть всё» в шапке возвращает общий вид, Esc сворачивает на уровень вверх, крошки в карточке — до выбранного уровня.
- Зум колесом детализацию не меняет. Ни клик, ни раскрытие, ни сворачивание карту не двигают; сама она двигается только по поиску, «Показать на карте» и ссылке.
- «Линза» в шапке перекрашивает карту по самым мелким районам по одному тегу (достаток, жители, улица, глаза, ночная жизнь, застройка, полиция), легенда — в углу карты; подробно — [TEXTS.md](TEXTS.md).
- «Все районы» — режим проверки: грузятся файлы детей всех узлов, видны сразу все листья, узлы выше — только контуром. Помнится в `vtm-dallas-2005-map.view`.
- Дети каждого узла лежат в отдельном файле и грузятся при первом раскрытии.
- Регионы раскрытой ветки — яркие (`focus`), соседи вокруг — бледнее (`ctx`), раскрытый узел — только контур (`exp`).
- Озёра и парки (`nature.geojson`) — отдельный слой поверх, кликается всегда.
- Режима дорог больше нет (убран 27 октября 2026: линии были рваные и в игре не нужны). Если через озеро идёт мост, это пишется в описании озера.

Подписи ставятся без наложения: сначала выбранный регион, потом регионы раскрытой ветки (крупные раньше), потом соседи, потом озёра и парки. В DOM лежат только видимые подписи, размер подписи считается через canvas `measureText`, без перерисовки страницы.

### Формат data/map.json

```json
{
 "schema": 5,
 "updated": "2026-10-27",
 "nodes": {"prestonhollow": {"marker": "important", "label": "Элизиум", "summary": "", "details": "…", "more": "", "notes": ""}},
 "nature": {"lake-whiterock": {"details": "…", …}}
}
```

Ключи `nodes` — id из `data/tree.tsv`, ключи `nature` — id из `data/natural.tsv`. Названия берутся из этих таблиц, а не из `map.json`.

| Поле | Значение |
|---|---|
| `marker` | `""`, `"haven"`, `"ally"`, `"hostile"`, `"important"`. Свёрнутый регион показывает пунктиром метку того, что у него внутри. |
| `label` | Подпись метки. |
| `summary` | Необязательная строка под заголовком. |
| `details` | Короткое описание, 3–5 предложений. Если своего текста нет, в карточке показывается описание ближайшего предка. |
| `more` | Справка под «Подробнее»: история и 2000–2005 годы. |
| `tags` | Ручные теги: `build`, `street`, `eyes`, `night`, `police` и пояснения к ним `notes` (см. [TEXTS.md](TEXTS.md)). |
| `notes` | Заметки мастера, видны всем. |

### Личные пометки

`localStorage`, ключ `vtm-dallas-2005-map.personal.v1`: `{"items": {"n:prestonhollow": {"marker": "…", "label": "…", "notes": "…"}}}`. `n:` — узел дерева, `nat:` — озеро или парк. Пометки прежней карты в четыре масштаба (`d:…`, `a:…`) при загрузке переносятся на узел в том же месте по `aliases.json`; импорт понимает и файл пометок старой карты в клетку. Переключатель «Все районы» помнится под `vtm-dallas-2005-map.view`.

### Ссылки

`#n/<id>` — выбрать узел (ветка к нему раскрывается), `#n/<id>+` — выбрать и раскрыть, `#nat/<id>`. Ссылки прежних карт (`#d/<id>`, `#city-D5` и т. п.) открывают узел в том же месте.

## Правила для описаний

1. Всё по состоянию на весну 2005 года. Если факт не проверить, лучше не писать.
2. Описывай то, что лежит в границах региона.
3. Как писать на каждом уровне дерева, теги и порядок работы — [TEXTS.md](TEXTS.md). Материал — тексты старой карты в `data/legacy/`.
4. Язык простой и живой, как у знающего друга, который объясняет мастеру из постсоветского пространства. Без канцелярита, списков, эмодзи и рекламы.
5. Названия мест транслитерируются по-русски, названия учреждений можно оставлять по-английски.
6. Никаких личных секретов игроков и закулисья мастера. Реальные люди — только исторический фон.
