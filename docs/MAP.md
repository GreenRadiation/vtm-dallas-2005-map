# Как устроена карта

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Оболочка страницы: шапка с кнопками, карта, карточка. Подвала нет: на компьютере страница сама не прокручивается, листаются только карточка и выдача поиска; легенда озёр и парков, ссылка на `review.html` и пояснение об источниках — внизу стартовой карточки (`INTRO` в `app.js`). Leaflet 1.9.4 с cdnjs и шрифты. |
| `assets/style.css` | Стили, включая цвета слоёв карты. Цвета — токены в `:root`, есть тёмная тема. |
| `assets/app.js` | Логика сайта: раскрытие веток дерева, карточки, поиск, личные пометки, ссылки. |
| `data/map.json` | Тексты и ручные теги регионов, озёр и парков. Пишется руками. |
| `data/dart.tsv` | Станции DART и TRE на весну 2005: название, линии, координаты, пояснение для подсказки. Правится руками. |
| `data/geo/dart.geojson` | Слой DART: линии и станции. Собирает `tools/dart.py` из `data/raw/osm_transit.json` и `data/dart.tsv`. |
| `data/census.json` | Перепись 2000 года по узлам дерева (кто живёт, доход, жильё). Собирает `tools/census.py`, руками не правится. |
| `data/tree.tsv` | Дерево регионов: id, родитель, вид (город, аэродром, знаковое место, группа), название, опорные точки. Пишется руками, см. [TREE.md](TREE.md). |
| `data/natural.tsv` | Озёра и большие парки — слой поверх дерева. |
| `review.html` | Список всех регионов со ссылками на Google Maps — для сверки. |
| `data/geo/tree/` | Готовая геометрия дерева: `_root.geojson` (верхний уровень), `<id>.geojson` (дети узла), `index.json` (все узлы: родитель, название, точка подписи, рамка), `aliases.json` (куда ведут ссылки и пометки прежних карт). Собирается скриптом, руками не правится. |
| `data/geo/*.geojson` | `nature` (озёра и парки), `water`, `green`. Тоже собираются скриптом. |
| `data/geo/regions.txt` | Дерево с площадями — для проверки глазами. |
| `data/legacy/` | Прежние версии: тексты карты в клетку (`grid-2005.json`), тексты и список регионов карты в четыре масштаба (`map-v4.json`, `review-v4.json`). На сайте не показываются; `review-v4.json` нужен сборке для таблицы старых ссылок. |
| `data/raw/` | Скачанные сырые данные, в репозиторий не попадают. |
| `tools/` | Скрипты сборки (Python 3.11, нужны `shapely` ≥ 2.1, `pyshp`, `numpy`, `scipy`). |

## Сборка геометрии

```
pip install shapely pyshp numpy scipy
python tools/fetch.py     # скачать OSM и перепись в data/raw/ (один раз)
python tools/build.py     # собрать data/geo/*
python tools/dart.py      # слой DART → data/geo/dart.geojson (линии из OSM обрезаны до 2005 года)
python tools/census.py    # перепись 2000 по узлам → data/census.json (после build.py; качает ~70 МБ один раз)
python tools/geocheck.py  # необязательно: сверить опорные точки дерева с геокодером OSM
```

Скрипты запускаются из корня репозитория. `build.py` работает около 20 секунд. Если проверки (см. REGIONS.md) не прошли, он печатает ошибки и не перезаписывает карту; `--force` записывает всё равно, для отладки.

### Регионы

Как устроено дерево и как его править — [TREE.md](TREE.md); как режется геометрия и какие проверки выполняет сборка — [REGIONS.md](REGIONS.md). Если проверки не прошли, сборка не перезаписывает карту. Список всех регионов для сверки — страница `review.html` (данные — `data/geo/review.json`).

### Анахронизмы

В начале `tools/build.py`: `ANACHRONISM_ROADS` (Margaret Hunt Hill Bridge, Chisholm Trail Parkway, все экспресс-полосы TEXpress, платные продолжения SH 360), `ANACHRONISM_PARKS` (Klyde Warren Park и новые скверы даунтауна), `anachronism_way` (западное продолжение платной дороги Буша по SH 161 и восточное до Роулетта). Дороги и железные дороги на карту не выводятся, но служат барьерами при нарезке регионов, поэтому анахронизмы из них тоже вырезаются. Lake Viridian (2010-е) не включён в природные регионы.

## Сайт

### Дерево

- Сначала видны только верхние узлы (города и пригороды). Клик — карточка. Двойной клик или «Раскрыть» в карточке раскрывает узел: на его месте появляются дети, сам он остаётся толстым контуром. Раскрыта всегда одна ветка; раскрытие другого узла сворачивает прежнюю ветку до общего предка. Простой клик ничего не сворачивает. «Свернуть всё» в шапке возвращает общий вид, Esc сворачивает на уровень вверх, крошки в карточке — до выбранного уровня.
- Зум колесом детализацию не меняет. Ни клик, ни раскрытие, ни сворачивание карту не двигают; сама она двигается только по поиску, «Показать на карте» и ссылке.
- Кнопка «DART» показывает поезда весны 2005 года: красная (Уэстморленд — Паркер-роуд) и синяя (Ледбеттер — Даунтаун-Гарленд) линии лёгкого метро, общий участок через центр — красно-синим пунктиром, тоннель под Центральным шоссе — штриховой обводкой, пригородный поезд TRE до Форт-Уэрта — коричневым. Станции — кружки с подсказкой, пересадочные крупнее. В углу карты — сворачиваемая справка: часы работы, полиция DART, TRE. Зелёной и оранжевой линий, A-Train и TEXRail в 2005 году нет.
- Границы Далласа и Форт-Уэрта обведены в шесть раз толще прочих отдельным слоем поверх регионов (`.cityline`), видны и при раскрытой ветке, и в линзе.
- «Линза» в шапке перекрашивает карту по самым мелким районам по одному тегу (достаток, жители, улица, глаза, ночная жизнь, застройка, полиция), легенда — в углу карты; подробно — [TEXTS.md](TEXTS.md).
- Поиск — одна строка по всему сразу. Сначала названия регионов, озёр, парков и меток, потом теги (клетки карточки вроде «Полиция — шериф», «Застройка — тюрьма» и теги меток), потом тексты описаний, пояснения тегов, тексты меток и заметок к регионам. Метки и заметки — только из видимых слотов. Слова сравниваются без окончаний («тюрьма» находит «тюрьмы», «тюрьмой»), слова от пяти букв после отбрасывания окончания — ещё и с одной ошибкой («эллум» находит Дип-Эллам); такие совпадения идут ниже точных. Запрос из одной-двух букв ищется только в названиях. Под найденным по тексту — кусок текста с подсвеченным словом. Наведение мыши (или фокус с клавиатуры) на результат обводит его на карте пунктиром (`.hovpath` в слое `sel`), метку — кольцом; карта при этом не двигается, файл детей родителя подгружается при необходимости.
- Точка отсчёта: кнопка «Отсчёт отсюда» в карточке региона, озера или метки делает её точкой, от которой считаются расстояния; в шапке появляется плашка «Отсчёт от …» (имя открывает точку, крестик убирает). В карточках пишется расстояние по прямой, примерный путь по дорогам и время на машине (и пешком, если ближе 5 км), в подсказках на карте — коротко. Дорог на карте нет, поэтому путь — прямая × 1,4 по городу и ближе к × 1,2 на дальних поездках, время — ночная езда без пробок: около 30 км/ч по улицам, до 90 км/ч по фривеям (`trip` в `app.js`). Регион считается по точке подписи, метка — по своим координатам. По умолчанию точки нет; выбор помнится в `vtm-dallas-2005-map.view` (`ref`).
- «Все районы» — режим проверки: грузятся файлы детей всех узлов, видны сразу все листья, узлы выше — только контуром. Помнится в `vtm-dallas-2005-map.view`.
- Дети каждого узла лежат в отдельном файле и грузятся при первом раскрытии.
- Регионы раскрытой ветки (`focus`) и соседи вокруг (`ctx`) залиты одинаково: карта никогда не затемняется, ни при раскрытии, ни при выборе региона (решено с автором 29 октября 2026). Раскрытый узел — только толстый контур (`exp`).
- Озёра и парки (`nature.geojson`) — отдельный слой поверх, кликается всегда.
- Режима дорог больше нет (убран 27 октября 2026: линии были рваные и в игре не нужны). Если через озеро идёт мост, это пишется в описании озера.

Подписи ставятся без наложения: сначала выбранный регион, потом регионы раскрытой ветки (крупные раньше), потом соседи, потом озёра и парки. В DOM лежат только видимые подписи, размер подписи считается через canvas `measureText`, без перерисовки страницы.

### Формат data/map.json

```json
{
 "schema": 5,
 "updated": "2026-10-27",
 "nodes": {"prestonhollow": {"summary": "", "details": "…", "more": "", "notes": ""}},
 "nature": {"lake-whiterock": {"details": "…", …}}
}
```

Ключи `nodes` — id из `data/tree.tsv`, ключи `nature` — id из `data/natural.tsv`. Названия берутся из этих таблиц, а не из `map.json`.

| Поле | Значение |
|---|---|
| `summary` | Необязательная строка под заголовком. |
| `details` | Короткое описание, 3–5 предложений. Если своего текста нет, в карточке показывается описание ближайшего предка. |
| `more` | Справка под «Подробнее»: история и 2000–2005 годы. |
| `tags` | Ручные теги: `build`, `street`, `eyes`, `night`, `police` и пояснения к ним `notes` (см. [TEXTS.md](TEXTS.md)). |
| `notes` | Заметки мастера, видны всем. |

### Метки игроков: слоты

Для игроков и для сборки файла меток — [MARKS.md](MARKS.md). Здесь — устройство.

Метки — точки на карте (значок, цвет, название, теги, текст) и заметки к регионам (свой цвет заливки или «не менять», теги, текст). Теги вписываются вручную, у каждого тега свой цвет, общий для слота. Лежат в слотах: слот — набор меток одного автора, хранится в браузере и сохраняется в файл отдельно. Загрузка файла заменяет только содержимое выбранного слота — так мастер раздаёт свои метки, а игроки обновляют их новой версией файла, не трогая свои.

- Меню «Метки» в шапке: глаз — показать или скрыть слот, имя — сделать слот активным (в него пишутся новые метки и заметки), карандаш — окно слота: название, «Сохранить в файл», «Загрузить из файла», «Удалить слот». Внизу — «Добавить новый».
- Поставить метку: «Поставить метку» в карточке региона, потом клик по карте; или правый клик (на телефоне долгое нажатие). Метку в режиме правки можно перетащить.
- Регион с цветом заливки красится, когда он виден на карте; если цвет задан в нескольких слотах, главнее активный.
- Встроенных меток на сайте нет: все метки, в том числе метки хроники, живут в слотах у игроков и мастера и раздаются файлами, чтобы мастер мог обновлять их без кода.
- Точки лежат под подписями регионов (панель `pins` ниже `labels`). Цвет нового тега выбирается квадратиком справа от поля ввода; по умолчанию — следующий свободный цвет палитры.
- Тексты описаний (`details`, `more`, `notes` в `map.json`), меток и заметок к регионам понимают базовый Markdown (`md` в `app.js`): `**жирный**`, `*курсив*`/`_курсив_`, `__подчёркнутый__` (как в Discord), `~~зачёркнутый~~`, `` `код` ``, ссылки `[текст](https://…)`, `> цитата`, `---` линия, списки `- ` и `1. ` (номер до трёх цифр, чтобы «2005. …» не стал списком), заголовки `#`–`###`. Текст сначала экранируется, HTML не проходит. Поиск и сниппеты работают по тексту без разметки (`plain`). Под полем «Текст» в формах — подсказка.
- Ускорения Leaflet в начале раздела «карта» в `app.js`. Шаги колеса, пришедшие во время анимации зума, Leaflet 1.9 выбрасывает, и карта «залипала» (8 щелчков доводили зум с 11 только до 12,5) — теперь они копятся и применяются после анимации. Меркатор каждой вершины кешируется в `LatLng._m`, при зуме остаётся умножение. Замер в Firefox 28 октября 2026: пересчёт после шага зума 3–11 мс в обычном виде, 12–36 мс в «Все районы» с линзой.
- «Показать на карте» в карточке метки и двойной клик по метке раскрывают ветку дерева до района, где стоит метка (например, Даллас › Ист-Даллас для Лоуэр-Гринвилл), камеру не двигают. Двойной клик ловится по двум быстрым кликам по той же метке (`lastPinClick`): первый клик перерисовывает значок, и браузерный `dblclick` до нового значка не доходит.

`localStorage`, ключ `vtm-dallas-2005-map.marks.v2`: `{"active": "<id слота>", "slots": [{"id", "name", "on", "tags": {"тег": "#rrggbb"}, "pins": [{"id", "ll": [широта, долгота], "icon", "color", "title", "tags": [], "text"}], "regions": {"n:<узел>" | "nat:<озеро>": {"color", "tags": [], "text"}}}]}`. Файл слота: те же `name`, `tags`, `pins`, `regions` плюс `"format": "vtm-dallas-2005-marks", "version": 2`.

При первом запуске пометки первой версии (ключ `vtm-dallas-2005-map.personal.v1`) переезжают в слот «Мои метки»: пометка с типом метки становится точкой в центре региона с тегом-типом, остальные — заметкой к региону (подпись — тег). Загрузка в слот понимает и старые файлы: `{items}` этой карты, ключи прежней карты в четыре масштаба и файл старой карты в клетку (`{cells}`) — по `aliases.json`. Вид карты (линза, DART, «Все районы») помнится под `vtm-dallas-2005-map.view`.

### Ссылки

`#n/<id>` — выбрать узел (ветка к нему раскрывается), `#n/<id>+` — выбрать и раскрыть, `#nat/<id>`. Ссылки прежних карт (`#d/<id>`, `#city-D5` и т. п.) открывают узел в том же месте.

## Правила для описаний

1. Всё по состоянию на весну 2005 года. Если факт не проверить, лучше не писать.
2. Описывай то, что лежит в границах региона.
3. Как писать на каждом уровне дерева, теги и порядок работы — [TEXTS.md](TEXTS.md). Материал — тексты старой карты в `data/legacy/`.
4. Язык простой и живой, как у знающего друга, который объясняет мастеру из постсоветского пространства. Без канцелярита, списков, эмодзи и рекламы.
5. Названия мест транслитерируются по-русски, названия учреждений можно оставлять по-английски.
6. Никаких личных секретов игроков и закулисья мастера. Реальные люди — только исторический фон.
