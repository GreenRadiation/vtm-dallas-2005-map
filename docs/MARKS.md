# Метки: как пользоваться и как собрать файл меток

Этот файл — для игроков, мастера и для ИИ-помощника, которого попросили подготовить метки. Его достаточно прочитать целиком, остальной репозиторий для этого не нужен.

## Что такое метки

Метки — личные пометки поверх карты. Их два вида:

- **Точка** — значок в конкретном месте карты: убежище, союзник, клуб, место встречи. У точки есть название, значок, цвет, теги и текст.
- **Заметка к региону** — текст, теги и, если хочется, свой цвет заливки для целого района, города, озера или парка: «здесь охотится наш гуль», «территория шабаша».

Теги пишутся свободно («Союзник», «Убежище», «Шабаш»), у каждого тега свой цвет.

Метки лежат в **слотах**. Слот — набор меток одного автора: «Мои метки», «Мастер», «Метки Джейн». Каждый слот можно скрыть, сохранить в файл и загрузить из файла. Загрузка заменяет содержимое только этого слота, остальные не трогает. Так мастер раздаёт игрокам свои метки, а игроки обновляют их новой версией файла, не теряя своих.

Всё хранится только в браузере игрока (`localStorage`). На сервер ничего не уходит, другие игроки чужих меток не видят, пока им не передали файл.

## Как пользоваться на сайте

- **Меню «Метки»** в шапке — список слотов:
  - глаз — показать или скрыть слот на карте;
  - имя слота — сделать его активным: новые метки и заметки пишутся в него;
  - карандаш — окно слота: название, «Сохранить в файл», «Загрузить из файла», «Удалить слот»;
  - «+ Добавить новый» внизу — новый пустой слот.
- **Поставить точку:** открой регион, нажми «Поставить метку» и кликни по карте. Или просто правый клик по карте (на телефоне — долгое нажатие). Откроется форма: название, значок, цвет, теги, текст, слот.
- **Изменить точку:** клик по точке → «Изменить». В режиме правки точку можно перетащить.
- **Заметка к региону:** открой регион → «Заметка к региону». Цвет: «не менять» или свой. Если заметки к региону есть в нескольких слотах, вверху формы выбирается, какую править.
- **Перенести в другой слот:** в форме точки или заметки — поле «Хранить в слоте», потом «Сохранить». Пункт «Новый слот» создаёт слот и переносит туда. Если в выбранном слоте уже есть заметка к этому региону, тексты и теги объединятся; теги переезжают со своими цветами. Если слот скрыт, форма предупредит.
- **Найти метку:** поиск в шапке ищет и по меткам: по названию, тегам и тексту.
- **«Показать на карте»** в карточке точки или двойной клик по точке раскрывает дерево до района, где она стоит.
- **«Отсчёт отсюда»** в карточке точки (или региона) делает её точкой отсчёта: в других карточках и подсказках пишется, сколько до неё ехать. Удобно поставить метку «Мы здесь» или выбрать своё убежище.

### Как загрузить чужой файл

1. «Метки» → «+ Добавить новый» (или карандаш у существующего слота, если обновляешь его).
2. В окне слота — «Загрузить из файла», выбрать `.json`.
3. Если в слоте уже что-то было, сайт спросит, заменить ли. Заменяется только этот слот.

## Формат файла меток

Файл — JSON в кодировке UTF-8, расширение `.json`. Обычное имя — `<название>-dallas-2005.json`.

```json
{
 "format": "vtm-dallas-2005-marks",
 "version": 2,
 "name": "Метки Джейн",
 "tags": {
  "Союзник": "#3a74cc",
  "Убежище": "#4c9a47",
  "Опасно": "#d6453a"
 },
 "pins": [
  {
   "id": "club1",
   "ll": [32.7843, -96.7836],
   "icon": "glass",
   "color": "#7b5ccc",
   "title": "Клуб, где работает знакомый бармен",
   "tags": ["Союзник"],
   "text": "Бармен Рикки, смена с десяти вечера.\nЗнает, кто в клубе свой."
  },
  {
   "id": "haven1",
   "ll": [32.8105, -96.7700],
   "icon": "home",
   "color": "#4c9a47",
   "title": "Запасное убежище",
   "tags": ["Убежище"],
   "text": ""
  }
 ],
 "regions": {
  "n:deepellum": {"color": "", "tags": ["Союзник"], "text": "Здесь у меня много знакомых среди музыкантов."},
  "n:dal-oakcliff": {"color": "#d6453a", "tags": ["Опасно"], "text": "Сюда ночью лучше не соваться."},
  "nat:lake-rayhubbard": {"color": "", "tags": [], "text": "У пристани встреча раз в месяц."}
 }
}
```

### Поля

| Поле | Что это | Обязательно |
|---|---|---|
| `format` | Всегда `"vtm-dallas-2005-marks"`. По нему сайт узнаёт файл. | да |
| `version` | Всегда `2`. | да |
| `name` | Название слота, до 60 знаков. Подставится, если слот новый. | нет |
| `tags` | Цвета тегов: `{"тег": "#rrggbb"}`. Тегам без цвета сайт сам раздаст цвета палитры. | нет |
| `pins` | Список точек. | нет |
| `regions` | Заметки к регионам: ключ — регион, значение — заметка. | нет |
| `exported` | Дата сохранения, сайт пишет её сам. При загрузке не читается. | нет |

**Точка** (`pins[]`):

| Поле | Что это |
|---|---|
| `id` | Любая строка до 20 знаков, уникальная внутри файла. Если не указать или повторить — сайт выдаст новый. |
| `ll` | Координаты `[широта, долгота]` в градусах, широта первой. Как в Google Maps: правый клик по месту → первая строка меню. |
| `icon` | Значок, см. список ниже. Неизвестный станет `dot`. |
| `color` | Цвет кружка, `#rrggbb`. Неверный станет красным. |
| `title` | Название, до 120 знаков. |
| `tags` | Список тегов, до 12, каждый до 40 знаков. |
| `text` | Текст, до 20 000 знаков, с Markdown (см. ниже). Переводы строк (`\n`) сохраняются. |

**Заметка к региону** (`regions["<ключ>"]`):

| Поле | Что это |
|---|---|
| `color` | Цвет заливки региона `#rrggbb` или `""` — не перекрашивать. |
| `tags` | Список тегов, как у точки. |
| `text` | Текст заметки, тоже с Markdown. |

Тексты меток и заметок понимают Markdown: `**жирный**`, `*курсив*` или `_курсив_`, `__подчёркнутый__`, `~~зачёркнутый~~`, `` `код` ``, `[ссылка](https://…)`, строка `> цитата`, строка `---` — линия, списки `- пункт` и `1. пункт`, заголовок `# Текст`. Пустая строка — новый абзац, одиночный перевод строки — перенос. HTML не проходит.

Ключ региона:

- `n:<id>` — регион дерева любого уровня: город (`n:dallas`), часть города (`n:dal-oakcliff`), район (`n:deepellum`).
- `nat:<id>` — озеро или парк (`nat:lake-rayhubbard`).

Заметки с неизвестным ключом при загрузке молча отбрасываются, так что id надо брать из списков ниже.

### Где взять id регионов

- **Список на сайте:** страница `review.html` (ссылка «Список всех регионов» внизу стартовой карточки) — все регионы с названием, id, родителем и ссылкой на Google Maps.
- **Тот же список файлом:** `data/geo/review.json` — массив `{"id", "name", "parent", "level", "lat", "lon", ...}`. Названия по-русски.
- **Дерево целиком:** `data/tree.tsv` — колонки id, родитель, вид, название, опорные точки. Как устроено дерево — [TREE.md](TREE.md).
- **Озёра и парки:** `data/natural.tsv`, первая колонка — id, последняя — название.
- **На сайте:** выбери регион — его id появится в адресной строке после `#n/` (озеро — после `#nat/`).

Чем мельче регион, тем точнее заметка: заметка к `n:dallas` видна, только когда на карте виден весь Даллас, а к району — когда раскрыта его ветка.

### Значки

| id | что | id | что |
|---|---|---|---|
| `dot` | точка | `skull` | череп |
| `home` | дом | `drop` | капля (кровь) |
| `glass` | бокал | `heart` | сердце |
| `building` | здание | `shield` | щит |
| `eye` | глаз | `crown` | корона |
| `star` | звезда | `flag` | флаг |
| `users` | люди | `key` | ключ |
| `alert` | опасность | `moon` | луна |
| `cross` | крест | `coin` | деньги |
| `blade` | клинок | `question` | вопрос |

### Палитра

Те же цвета, что предлагает форма на сайте; можно и любые другие `#rrggbb`.

`#d6453a` красный · `#e8892b` оранжевый · `#e3c22f` жёлтый · `#4c9a47` зелёный · `#2a9187` бирюзовый · `#3a74cc` синий · `#7b5ccc` фиолетовый · `#c4509b` розовый · `#8a6a2c` коричневый · `#5f6876` серый

### Охват карты

Карта покрывает примерно широту 32.58–33.08 и долготу −97.55…−96.50: Даллас, Форт-Уэрт и пригороды. Точки за пределами тоже загрузятся, но их не будет видно.

## Если файл готовит ИИ-помощник

- Отдай файл человеку, который попросил. **Не коммить его в этот репозиторий:** репозиторий и сайт публичные, а в метках обычно секреты персонажа.
- Координаты бери по реальному адресу места (как он был в 2005 году), а не центр региона — точки в центре региона наезжают на его подпись.
- Если место выдуманное, ставь точку в правдоподобном месте нужного района и упомяни в `text`, что это условное место.
- Один файл — один слот. Если меток для разных людей несколько наборов, сделай несколько файлов.
- Перед выдачей проверь, что JSON валидный, `format` и `version` на месте, а ключи `regions` есть в `data/geo/review.json` или `data/natural.tsv`.

## Для разработчика

Хранилище — `localStorage`, ключ `vtm-dallas-2005-map.marks.v2`: `{"active": "<id слота>", "slots": [{"id", "name", "on", "tags", "pins", "regions"}]}`. Код — раздел «метки: слоты» в `assets/app.js` (`cleanSlot` проверяет и чистит всё, что пришло из файла). Загрузка понимает и старые файлы: пометки первой версии этой карты (`{items}`) и файл карты в клетку (`{cells}`), ключи прежних карт переводятся по `data/geo/tree/aliases.json`. Подробности — в [MAP.md](MAP.md), раздел «Метки игроков: слоты».
